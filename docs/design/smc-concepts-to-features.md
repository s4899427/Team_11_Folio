# Social/Mobile Computing Concepts → App Features

| Concept | What It Means | Where It Shows Up In Our App |
|---|---|---|
| **Location-awareness** | System uses the user's physical location to shape content | "Nearby/Scene" tab — festivals, gigs, art shows near you |
| **Location-based recommendations (LBR)** | Suggesting content/people/events based on proximity | Surfacing nearby drops, nearby scenes, nearby users with similar taste |
| **Geofencing** | Triggering content when entering a defined area | Notification/content unlock when physically at a festival or event ("you're here — see the scene's drops") |
| **Location-based social networking (LBSN)** | Social interaction combined with geographic context | The whole Nearby/Scene layer — precedent: Foursquare-style check-in networks |
| **Proximity-based discovery** | Finding nearby users/content without explicit search | Browsing drops from people currently at the same event/area |
| **Check-ins / place-tagging** | Users marking themselves at a location or event | Tagging a Drop with the festival/event/location it was made at |
| **Awareness** | Knowing what others in your circle are doing/wearing/listening to | Home feed — seeing friends'/scene's latest drops |
| **Peripheral awareness** | Ambient, low-effort awareness vs. active checking | Passive scrolling of the home feed without deliberate searching |
| **Coordination** | Organizing shared activity between users | Friends coordinating outfits/playlists for the same event before it happens |
| **Collaboration** | Users jointly creating something together | Drop & Remix — the core mechanic, forking someone's music+fit pairing |
| **CSCW (Computer-Supported Cooperative Work)** | Academic framework for tech supporting group work | Theoretical grounding for the whole social layer — cite as your framework |
| **Synchronous interaction** | Real-time, co-present activity | Live "Scene mode" — co-styling/co-curating with friends physically together at an event |
| **Asynchronous interaction** | Delayed, non-real-time activity | Remixing someone's drop days/weeks after it was posted |
| **Persistent vs. ephemeral content** | Whether posts last or disappear | Design decision: Drops persist (so remix chains stay visible over time) |
| **Augmented Reality (AR)** | Overlaying digital content onto the real world | Dress-up tab — layering tops/bottoms onto a figure/photo |
| **Markerless AR** | AR tracking without a predefined visual marker | If real-time body tracking is attempted for the AR try-on |
| **Marker-based AR** | AR requiring a predefined marker to anchor content | Simpler fallback: static image compositing instead of live tracking |
| **Context-aware computing** | System adapts based on situational context (location, time, social setting) | Umbrella concept tying together the Nearby/Scene tab + AR + home feed personalization |
| **Mixed reality** | Blending physical and digital experience more broadly | Broader framing for AR dress-up + real-world event integration |
| **Social presence** | Sense of "being with" others in a digital space | Feeling connected to a scene/crew even when posting asynchronously |
| **Identity performance / self-presentation** | Curating what you show online | Core to the entire concept — every Drop is a curated identity statement (ties to Goffman) |
| **Social capital** | Value/status gained through visibility and connections | Why users want their drops seen/remixed — status within their scene |
| **Network effects** | App gets more valuable as more people join | More scenes/users = richer Nearby tab, more remix chains, more discovery |
| **User-generated content (UGC)** | Content created by users, not the platform | The entire Drop & Remix system — no editorial/brand content driving it |
| **Ubiquitous computing** | Computing embedded into everyday contexts, not desktop-bound | Foundational framing for why this has to be mobile-first |
| **Contextual mobility** | Mobile use shifts based on where/when someone is | Morning routine (fast, low-effort) vs. festival prep (deep, expressive) — your two personas |
